# Calculator (Hidden Vault)

একটা সাধারণ ক্যালকুলেটরের মতো দেখায়, কিন্তু ভিতরে **গোপন ভল্ট** আছে।

## কিভাবে ব্যবহার করবেন

### সাধারণ ক্যালকুলেটর
অ্যাপ খুললেই স্বাভাবিক ক্যালকুলেটর দেখাবে। যোগ, বিয়োগ, গুণ, ভাগ সব কাজ করবে।

### গোপন ভল্ট খোলা
ডিফল্ট PIN: **`1234`**

1. ক্যালকুলেটরে `1234` টাইপ করুন
2. `=` বাটন চাপুন
3. ভল্ট খুলে যাবে

### ভল্টে ফাইল রাখা
- **+ Add Photo / Video / File** বাটনে চাপুন
- গ্যালারি বা ফাইল পিকার থেকে ছবি/ভিডিও/যেকোনো ফাইল সিলেক্ট করুন
- ফাইল অ্যাপের প্রাইভেট স্টোরেজে সেভ হবে (অন্য অ্যাপ দেখতে পাবে না)

### PIN পরিবর্তন
ভল্ট খোলার পর উপরে লক আইকনে চাপুন → নতুন PIN সেট করুন

### ভল্ট লক করা
উপরে ✕ আইকনে চাপুন

## Features
- সম্পূর্ণ সাধারণ ক্যালকুলেটর ইউআই
- সিক্রেট PIN দিয়ে ভল্ট আনলক
- ছবি, ভিডিও, যেকোনো ফাইল স্টোর
- অ্যাপের প্রাইভেট স্টোরেজ (বাইরে থেকে দেখা যায় না)
- PIN পরিবর্তন করার অপশন

## Build
Android Studio দিয়ে খুলে Run করুন অথবা GitHub Actions থেকে APK ডাউনলোড করুন।
