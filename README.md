# Calculator - Android App

একটা সুন্দর Dark Theme Calculator অ্যাপ (Kotlin + Jetpack Compose)

## কিভাবে চালাবেন

1. **Android Studio** খুলুন (নতুন ভার্সন সুপারিশকৃত)
2. **File → Open** করে এই প্রজেক্ট ফোল্ডার সিলেক্ট করুন
3. Gradle Sync হতে দিন (ইন্টারনেট লাগবে)
4. উপরের **Run** বাটনে ক্লিক করুন
5. Emulator বা আপনার Android ফোন কানেক্ট করে চালান

## Requirements
- Android Studio Hedgehog (2023.1.1) বা নতুন
- JDK 17
- Minimum Android 7.0 (API 24)

## Features
- যোগ (+), বিয়োগ (−), গুণ (×), ভাগ (÷)
- Clear (C)
- Backspace (⌫)
- Percentage (%)
- Decimal point (.)
- iPhone-style Dark Theme
